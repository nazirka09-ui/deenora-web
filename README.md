# Deenora Web

Приложение: https://nazirka09-ui.github.io/deenora-web/

На iPhone откройте в Safari → «Поделиться» → «На экран Домой».
Прогресс сохраняется в браузере на устройстве. Веб-версия включает цветной таджвид.

Этот репозиторий содержит только готовую веб-сборку. Исходники и ключи подписи
приложения сюда не публикуются. Новые сборки публикуются из основного проекта
командой `npm run deploy:web`.
